## Overview

Entropy: Zero 2 Config is a settings management tool for the acclaimed Half-Life 2 total conversion Entropy: Zero 2, providing a GUI for configuring launch options, graphics settings, accessibility toggles, and autosave behavior without hand-editing config files or launch arguments.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Entropy Zero 2 Config** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Launch Options** | Configure Source Engine launch flags via checkboxes and inputs |
| **Graphics Settings** | Set resolution, anti-aliasing, and shadow quality via GUI |
| **Accessibility** | Toggle closed captions, colorblind mode, and subtitles |
| **Autosave Config** | Set autosave frequency and checkpoint trigger behavior |
